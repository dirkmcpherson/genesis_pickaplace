# Trial176 physical review

`176_soft2_real_sim.mp4` contains the full74.43s source,414 decoded frames,
two real cameras and saved simulation overview/hand poses. Every frame decoded;
video/trace hashes match. Maximum timestamp mismatch is16.70ms /21.88ms.
Selected release/push/endpoint frames and real-camera detail sheets were inspected.
This is not a registered camera overlay or frame-by-frame geometric calibration.

Original strict first separation is36.42s; latest soft2 first separation is27.39s.
These events do not represent final withdrawal: fingers recontact the can. Real
frames show the can lowering during gradual opening25–30s and remaining beside
the fingers until about36s. Earlier simulated settling is qualitatively consistent
with that observation, but exact real support/contact timing is not established.
Do not label the nine-second change itself a measured timing error or correction.

Soft2 completes a supported final slide and withdrawal while shifting the goal
0.028mm (original7.629mm). Hand seating/curl still differ. This is a possible local
fidelity improvement, not a new recovered demo or proof of the overall objective.
