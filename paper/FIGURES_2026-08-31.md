## fig7_real_vs_sim — the real command tapes vs what the sim training sets retain (added 08-31 pm; 09-02: split into fig7a_real_vs_sim_tapes = per-tape metrics, fig7b_real_vs_sim_sets = distances + coverage)
Real side = FK of the recorded 60 Hz joint-position command streams through the same URDF the sim
uses (`extract_real_tape_stats.py`; COMMANDED kinematic path — the executed real path lives only
in the bags, task-3 machine). Sim side = the fig6 matched sets; same-trial pairing via ic_uid =
real trial uid (56 matched trials); paths start-aligned (absorbs the 3 cm mount offset).
FINDINGS:
- The real commanded signal is far richer than what survives re-execution: path length 1.83 m vs
  0.49/0.53 m (old/corrected), wander 0.095 vs 0.061 m, pooled coverage 731 voxels vs 374 (old)
  and 449 (corrected). The replay/execution stack is a heavy low-pass filter on the human data —
  and the CORRECTED world retains ~20 % more of the real coverage than the old world (449 vs 374
  on identical trials).
- Idle: 50 % of real frames command no joint movement (60 Hz frame level) — the raw material of
  the pruning story (matched dH sets are leading-idle-pruned → ~0).
- Same-trial shape distance real↔replay ≈ 0.19 m in BOTH worlds — and real↔DP-teacher is the
  same magnitude (0.185): the faithful "replay" of a human demo is no closer in path shape to the
  commanded signal than the DP teacher's independent rollout on that IC.
CAVEATS (load-bearing, fig7): the real path is commanded, not executed — 60 Hz command dithering
inflates its length/coverage relative to the smoothed executed sim tapes, so the multipliers
(3.5× path, 2× coverage) are upper bounds on "signal lost"; the qualitative ranking
(real > corrected > old retention) is the defensible claim. Same-trial distances are arc-length-
resampled SHAPE distances; the length mismatch itself contributes. Executed-real comparison
(bag tool_pose) is the task-3 machine's follow-up and would tighten all of this.

## fig12 — how dH (raw) differs from dHpruned (pruned) as DATASETS (added 09-02, user Q4b, appendix)
Script `make_fig12_dataset_diff_2026-09-02.py`; inputs `raw_vs_pruned_tapes.csv` (one row per tape, 255

  (14,323 vs 7,129 = 2.01×). Same-IC ratio median 1.16 (old) / 1.20 (corrected), max 2.46 / 2.47; 12/60 and
