# WM_METRIC — what still separates human from machine demos in the corrected world (2026-09-01)

**Question.** In the corrected world (w3), EEF-position coverage of machine demos is nearly
human-level (−5 %, fig6) and RLPD shows NO source effect (A20 pre-registered null, RESULTS §2.3) —
yet r2dreamer still strongly prefers human demos (4/4 vs 1/4 seeds ignite at n=4, §3.1; n=8 landing
~09-01). What tape-measurable property, beyond visited-state coverage, does a DYNAMICS-learning
consumer still care about when a VALUE-SUPPORT consumer does not?

**Status: SCREENING STUDY — hypothesis-generating, not confirmatory.** 33 per-tape + 5 set-level
metrics were screened on the same 228 tapes; p-values are unadjusted for multiple comparisons; the
ranking criterion was declared before any metric was computed, but the metric battery itself was
assembled by the analyst. The winner earns a pre-registered ablation (§5), nothing more.

## 1. Data and method

- **Data (read-only, frozen):** cluster `baselines/matched_v2/{dH,dDP}` (old world, 56+56 tapes)
  and `baselines/matched_w3/{dH,dDP}` (corrected world, 58+58), contract-v1 npz, images never
  loaded. Metadata verified IDENTICAL across all four sets (act_mode sample, action_repeat 4,
  delta_cap 0.025, delta_leash 0.125, delta_ref target, recorder record_demos.py v1) → per-step
  kinematics and spectra are directly comparable. w3 sim_variant = gc_kp4_riser3_shelf6.
  State columns verified empirically: joints 0:6, grip pos 6, grip effort 7, can xyz 8:11,
  can quat(wxyz) 11:15, goal xy 15:17. One tape per IC in every set (so "per-IC multimodality"
  is measured across nearest-neighbour ICs, not within an IC).
- **Script:** `baselines/diagnostics/tape_dynamics_metrics.py` (this repo; run on cluster login
  node, niced, CPU, ~4 min). Outputs: `tape_dyn_metrics.csv` (per-tape; committed copy in
  paper/figures/), `set_level_metrics.csv`, `ranking.md`. Figure:
  `paper/figures/make_fig8_wm_metric_2026-09-01.py` → `fig8_wm_metric.{png,pdf}`.
- **Pre-declared criterion** (fixed in the task statement before computation): per-tape metrics →
  signed Cohen's d (dH − dDP, pooled SD) per world; **C = d_w3 − d_old** (we want w3-specific
  separators; coverage already separates the old world). Set-level metrics (one number per set) →
  bootstrap z (B=1000 over tapes), C_z = z_w3 − z_old, in a SEPARATE table (z ≠ d; z scales with n,
  but n is ~equal across worlds so within-table comparison is fair). ALL metrics computed are
  reported below — nothing dropped.

## 4. Reading (hypothesis) — revised by Addendum 2: the robust core is "full stops +
## faster moving speed" (bimodal speed), NOT whole-tape HF power

**The metrics that separate specifically in the corrected world form one family: temporal
burstiness of the motion.** In w3, human tapes pause 1.7× more of the time (pause_frac 0.29 vs
0.17, d +1.35), carry ~1.7× more high-frequency action power (act_hf_frac 0.083 vs 0.048, d +1.07),
and are jerkier per metre of path (d +0.53) — while their geometry (wander, path_len, tortuosity,
coverage) is indistinguishable-to-slightly-narrower. Machine tapes are temporally homogeneous:
smooth, near-constant-speed sweeps (higher act_autocorr, higher speed permutation entropy —
i.e. less repeated/structured speed patterning — and MORE spurious micro-transition kinds from
dither, see below).

Confound checks worth recording:
- **act_hf_frac's #1 rank is partly an old-world artifact.** Its C (+3.39) is inflated by a SIGN
  FLIP: the old-world DP teacher dithers (act_signflip_rate 0.44/step, and old-world
  corr(hf_frac, signflip) = +0.80 → old "HF power" IS dither). In w3 the correlation structure
  changes: corr(hf_frac, jerk_per_len) = +0.74 while corr(hf_frac, signflip) = −0.33 → w3 human HF
  power is real accel/decel bursts, not noise. The interpretively cleanest w3 separators are
  therefore **pause_frac** (large, same-sign in both worlds, bigger in w3) and **jerk_per_len**
  (sign flips old→w3), with act_hf_frac as their spectral signature.
- pause_frac and act_hf_frac are only weakly correlated in w3 (+0.27) — burst content and dwell
  content are semi-independent, and both point human-ward.
- pause_frac is a RELATIVE threshold (0.2× the tape's own median speed) and the matched dH sets are
  leading-idle-pruned, so this is mid-trajectory stop-and-go, not dataset idle padding.
- Tape lengths are matched (n_rows d −0.13), so none of this is a length artifact; action_repeat
  and delta caps are identical across sets, so none of it is a pipeline artifact.

**Why a dynamics learner would care while a value-support learner does not:** RLPD uses demos as
off-policy (s,a,r,s') support for the critic — visited-STATE coverage is what matters, and in w3
that is matched (−5 %). A world model must learn the MAP (s,a)→s': stop-and-go tapes excite the
dynamics across acceleration transients, near-zero-velocity regimes, static-friction/settling
behaviour, and high-|a| onsets — regions a constant-speed sweep never samples even when it visits
the same positions. Human tapes are, in system-identification terms, a richer excitation signal.
This is a hypothesis, not a demonstrated mechanism: with n=8 seeds/arm and per-SET (not per-seed)
metrics, no quantitative correlation with WM ignition is possible — only the ablation below can
test causality.

## 5. Ablation proposals (small pre-registered WM run)

All interventions produce contract-v1 tapes via open-loop re-execution in the w3 env with the
existing verify gate (only verified successes kept, sets re-matched on ICs) — same recorder, so the
consumer cannot tell the sets apart except through the intervention. Read-only on the source sets.

- **A1 — burst-injection re-timing of dDP (primary; raises pause_frac + act_hf_frac + jerk_per_len
  toward human):** take each w3 dDP action tape; re-time it along its own path by (i) inserting
  hold (zero-delta) segments with dwell statistics sampled from the same-IC human tape, and (ii)
  merging adjacent deltas up to delta_cap to create speed bursts, so total path is unchanged but
  the speed profile is human-matched. Geometry/coverage stays ~fixed; only temporal structure
  moves. Build: ~0.5–1 day scripting on top of the replay/record_demos infra + a few CPU-hours of
  re-execution/verification for ~58 tapes (yield risk: holds change little in the stiff
  gravity-compensated world, expect high verify pass rate; keep only passes, re-match).
- **A2 — de-pausing/smoothing of dH (converse; lowers the metrics):** constant-arc-speed re-time of
  each w3 human tape (delete sub-threshold steps, re-blend deltas under delta_cap), re-execute,
  verify. Same cost as A1. Prediction: human advantage shrinks.
- **A3 — DART-style i.i.d. action noise on dDP (control; the retired H3):** raises hf_frac and
  signflip WITHOUT structured pauses/bursts. If A1 ignites the WM and A3 does not, the causal
  ingredient is structured stop-and-go excitation, not raw action bandwidth — and this cleanly
  closes the loop on the old H3 hypothesis. Build: hours.
- **Pre-registered test (needs its own PREREG entry before launch):** r2dreamer, w3, dense, 3M,
  arms {dDP, dDP-retimed(A1), dDP+noise(A3), dH, dH-smoothed(A2)} × 4 seeds, packed 2–4/GPU
  (~12 new runs beyond the existing n=8 dH/dDP → ~2 GPU-days). Registered statistics: ignition rate
  (BEST hold ≥ 10/15) and BEST rnd, protocol identical to §3.1 re-scores. Registered predictions:
  ignition(dDP-retimed) > ignition(dDP); ignition(dH-smoothed) < ignition(dH);
  ignition(dDP+noise) ≈ ignition(dDP). Any other outcome falsifies the burstiness hypothesis.
  (No GPU jobs were launched by this analysis; this is the proposal.)

## 6. Caveats (load-bearing)

1. **Multiple comparisons:** 38 metrics screened on one frozen dataset; w3 perm p-values are
   unadjusted and several would survive Bonferroni (pause_frac, act_hf_frac, signflip, autocorr,
   trans_entropy all p<0.001 at α/38≈0.0013) — but the RANKING itself is exploratory. Winner =
   hypothesis, pending §5.
2. The criterion C was pre-declared, but the metric battery was analyst-chosen; family sizes are
   uneven (12 temporal vs ~5 coverage), which biases what "tops the table" toward the larger family.
3. act_hf_frac's top rank mixes two phenomena (old-world dither reversal + w3 human bursts); see §4.
4. dH tapes are RE-EXECUTED human commands — the execution stack already low-pass-filters the real
   signal (fig7: real commanded path 3.5× longer). The human-vs-machine burstiness gap measured here
   is a LOWER bound on the raw-command gap; conversely all claims are about what the learners
   actually consumed, which is the right object for the WM question.
5. Set-level z and per-tape d are different scales; they are never ranked in one table.
6. n=8 WM seeds/arm and per-set metrics → no seed-level correlation is possible; the WM link is
   qualitative until §5 runs.
7. matched_w3 counts (58/58) match fig6's; if the sets are ever regenerated (A26 demo-recovery
   work is active) this analysis must be re-run — the CSVs record uid/ic_uid per row for auditing.

## A1.1 Design decisions of record (each disclosed, none silent)

1. **Schedules are built from the RECORDED absolute command stream** (`actions[:, :6]`
   = the env's `_dj_target` at each decision end, grip = `actions[:, 6]`), not from a
   reconstruction — leash effects in the original recording are baked in; geometry is
   preserved exactly (re-timing moves waypoints ALONG the same path).
2. **Closure-dwell guard:** arc-length warping compresses the source tape's own pauses
   to zero decisions — including the grasp (the grip closes while the arm is still).
   At the closure arc position the builder splices hold decisions replaying the
   source's own grip ramp, so every schedule gives the gripper the decisions its
   source used. Without this, picks fail for timing reasons unrelated to the
   hypothesis. Inserted counts are in `transform_manifest.json`.
3. **dDPnoised = bounded i.i.d. WAYPOINT jitter, moving decisions only.** Two
   deviations from textbook DART, both forced by the open-loop delta MDP and both
   pre-flight-motivated: (i) i.i.d. noise on DELTAS integrates into an unbounded
   target random walk under delta_ref='target' open-loop — waypoint jitter is the
   bounded i.i.d. equivalent; (ii) jittering still waypoints DESTROYS the source's
   pauses (pre-flight: pause_frac 0.20 → 0.07), which would change stop-go structure
   in the control arm whose whole point is bandwidth-only — so decisions below the
   pause rule (d ≤ max(2e-3, 0.2·median)) and the closure segment keep zero noise.
   Sigma calibrated on the predicted stream to the measured dH HF level:
   **sigma = 0.003 rad** (grid in the manifest; pred hf 0.0829 vs target 0.0828).
4. **Horizon:** recorded with `--max-sim-steps 2400` (stamped per tape, A26
   convention) so no schedule truncates at the 1200 default; eval horizons unchanged.
5. **ICs reproduce the frozen tapes'** (reset(uid) where resettable, frame-0 pose
   reset otherwise, mirroring the frozen recordings), with a 5 mm post-reset can-pose
   sanity check in the adapter.
6. **Verify gate on** (open-loop replay re-pick, as all recorded sets). Deterministic
   for an open-loop adapter — kept for gate parity and nondeterminism detection.

## A2.1 What was fragile

1. **pause_frac (relative 0.2×tape-median threshold):** with ~50 % of frames near zero
   in both arms, the median sits at the dwell/move boundary — the metric can swing with
   small speed-scale changes. At a loose ABSOLUTE threshold (2 mm/decision) the arms are
   indistinguishable (0.50 vs 0.48, d +0.17). The separation lives at TRUE zero:
   | stop threshold (mm/decision) | dH_w3 | dDP_w3 | d_w3 | d_old | C |
   |---|---|---|---|---|---|
   | 0.2 | 0.238 | 0.052 | **+2.02** | +0.86 | +1.16 |
   | 0.5 (strict_stop_frac) | 0.365 | 0.221 | +1.15 | +0.60 | +0.55 |
   | 1.0 | 0.437 | 0.372 | +0.50 | +0.20 | +0.30 |
   | 2.0 | 0.503 | 0.483 | +0.17 | +0.09 | +0.08 |

## A2.2 Corrected headline (same mechanism, sharper operationalization)
